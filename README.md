# Domain-calibrated QSAR and structure-based screening of natural products against HCC kinases

Which natural products are credible inhibitor candidates against the receptor
tyrosine kinases that drive hepatocellular carcinoma, and how much confidence
does the evidence actually support?

This repository screens the COCONUT natural-product library (690,177 unique 2D
parents) against three HCC receptor tyrosine kinases — **EGFR** (`1M17`),
**FGFR4** (`5JKG`) and **VEGFR2** (`4ASD`) — with scaffold-split QSAR, Mondrian
split-conformal calibration, scaffold-level novelty filtering and orthogonal
AutoDock Vina validation.

**The headline result is about the method, not the molecules.** Every control in
this pipeline was built so that it could fail, and on two of three targets it
did. The applicability domain — the filter that decides whether a prediction is
trustworthy at all — turns out to depend on a tolerance parameter that published
screening work almost never states. At the value used here it switches itself
off on two of three targets, admitting the entire library as "in domain" at a
median training-set similarity of 0.18. A filter that admits everything is not a
filter. That is reported here as the finding rather than buried, and it is why
the hit counts below are quoted on the conformal-interval criterion and never on
the in-domain count.

So this is a methods and negative-results study. It is not a hit-discovery
paper: there is no experimental validation, and the single target that survives
every one of its own controls is VEGFR2.

## The finding: the domain threshold depends on an unreported parameter

`tau` is the max-Tanimoto similarity below which a compound is called
out-of-domain. It is derived from an isotonic fit of conformal half-width against
similarity, subject to a *width budget* — how wide an interval you are willing to
call reliable. That budget is a free parameter. Sweeping it:

<!-- BEGIN:tau-sweep -->
| Width budget (pIC50) | EGFR | FGFR4 | VEGFR2 |
|---|---|---|---|
| 1.0 | 0.7 binding | no fit | no fit |
| 1.25 | 0.7 binding | 0.7 binding | 0.7 binding |
| 1.5 | 0.6 binding | non-binding | 0.5 binding |
| **1.65 (used)** | non-binding | non-binding | 0.5 binding |
| 2.0 | non-binding | non-binding | non-binding |
<!-- END:tau-sweep -->

The ordering is not even consistent across targets, which sharpens the point:
the domain filter's existence is not a property of the chemistry alone. Both
tables on this page are generated by `scripts/make_readme_tables.py` from
`results/metrics/`, and a test fails if they drift from it.

## Evidence per target, including where it fails

| Target | AD threshold | Library in domain | Interval-active hits | Redocking top-1 RMSD | Enrichment ROC-AUC (95% CI) | Clears its null |
|---|---|---|---|---|---|---|
| EGFR | `tau` = 0.0 (non-binding) | 100.00% | 34 (1 on novel scaffolds) | 8.004 Å **fail** | 0.444 [0.327, 0.560] | **none** |
| FGFR4 | `tau` = 0.0 (non-binding) | 100.00% | 3,220 (2,977 on novel scaffolds) | 3.334 Å **fail** | 0.696 [0.592, 0.791] | ROC-AUC, EF5%, BEDROC |
| VEGFR2 | `tau` = 0.5 | 0.30% | 111 (7 on novel scaffolds) | 0.577 Å pass | 0.693 [0.585, 0.792] | ROC-AUC, BEDROC |
<!-- END:evidence-table -->

Read down the VEGFR2 row: the threshold binds, redocking reproduces the
crystal pose, and enrichment excludes 0.5 and clears a label-shuffled null. Read
the other two and the chain breaks. FGFR4 supplies 3,220 of the 3,271 hits while
failing redocking and having no working domain filter, so the bulk of the
shortlist rests on the weakest evidence — recorded as limitation V7, not smoothed
over. EGFR fails every independent check applied to it and is arguably a negative
control rather than a target.

Figures are in `results/figures/`.

## Method, and the assumptions it rests on

**Labels.** Human binding-assay IC50 from ChEMBL. `standard_relation` is
preserved: `<` / `<=` bound potency from below, `>` / `>=` from above, and only
uncensored records are used as regression targets. Structures are salt-stripped,
neutralised and tautomer-canonicalised, then deduplicated on the parent InChIKey.

**Splitting.** Generic Bemis-Murcko scaffold splits, strictly disjoint. A
deterministic canonical split carries the headline numbers with percentile
bootstrap CIs; repeated random scaffold splits measure split variance, which is
not the same thing as generalisation to new chemistry and is labelled as such.

**Model.** The family used downstream is chosen by the benchmark
(`results/metrics/model_selection.json`), not fixed in advance. Hyperparameters
are library defaults and were not tuned against any reported split. The margin
over a nearest-neighbour similarity baseline mostly sits inside one seed's
standard deviation, which is reported rather than defended.

**Calibration.** Mondrian split-conformal intervals at 90%, with the taxonomy
given by max-Tanimoto to the training set. `tau` is read off an isotonic fit of
half-width against similarity and reported with a bootstrap CI and a sensitivity
analysis, because a threshold that gates an entire screen should not rest on one
noisy bin.

> **Validity.** Split-conformal coverage holds under exchangeability. Held-out
> ChEMBL scaffolds satisfy it; a natural-product library does not. Intervals
> attached to library compounds in step 05 are therefore an error model
> calibrated on synthetic chemistry and extrapolated — labelled that way in every
> output file, and `interval_lower_bound_active` is never described as a
> guaranteed-coverage hit.

**Screening.** The library is deduplicated to 2D parents before screening, since
the features are achiral. Hits are scored for novelty at the scaffold level, not
only by similarity, and flagged for pan-kinase frequent-hitter chemotypes. A
similarity-search baseline ranks the same library, so the model's added value is
measured rather than assumed.

**Docking.** Top-1 symmetry-corrected RMSD measured in place is the redocking
control; best-of-N is reported beside it as a sampling diagnostic. The enrichment
control uses randomly sampled, property-matched actives and true censored
inactives with bootstrap CIs, EF1%, EF5% and BEDROC, each against a
label-shuffled null on the same balanced design, where the usual thresholds do
not mean what they normally do. Boxes are sized to the ligand, replicate seeds
give error bars, and Vina scores are compared within a target only.

## Quick start

```bash
git clone https://github.com/thinkiamparanoid2/hcc-kinase-conformal-screen.git
cd hcc-kinase-conformal-screen

# Conda (includes AutoDock Vina and Open Babel for step 06)
conda env create -f environment.yml && conda activate hcc-screen

# or: pip install -r requirements.txt   (steps 01-05 and 07 only)

pytest -q                          # unit tests, no external data needed
python scripts/run_pipeline.py --list
python scripts/run_pipeline.py     # full pipeline, checkpointed and resumable
```

Steps that need external inputs are skipped with a named reason rather than
failing: step 05 needs the COCONUT library (see [`data/README.md`](data/README.md))
and step 06 needs `vina` and `obabel` on `PATH` (or `VINA_BIN` / `OBABEL_BIN`).

See [`docs/REPRODUCE.md`](docs/REPRODUCE.md) for the full reproduction path,
[`docs/commands.md`](docs/commands.md) for per-step commands, and
[`docs/roadmap.md`](docs/roadmap.md) for where the work stands and what is worth
doing next.

## Known limitations

Maintained in [`docs/limitations.md`](docs/limitations.md) and regenerated into
section 5 of the report from the pipeline's own measurements. The load-bearing
ones: conformal validity does not transfer to natural products (C1); the domain
filter is vacuous on two of three targets (V6); the hit list is dominated by the
target with the weakest validation (V7); receptor preparation is not bit-for-bit
reproducible, so docking scores are only approximately so (K14); and there is no
experimental validation of any predicted compound (G1).
