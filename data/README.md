# Data Directory Structure

This directory holds the curated kinase bioactivity datasets, receptor crystal structures, natural-product screening library, and engineered molecular features.

## Subfolders

- `targets/` (tracked in Git):
  - `egfr_1m17.pdb`, `egfr_1m17.pdbqt`, `EGFR_clean_receptor.pdb` — EGFR kinase domain in active DFG-in conformation bound to Erlotinib (`AQ4`, centroid `[22.01, 0.25, 52.79]`).
  - `fgfr4_5jkg.pdb`, `fgfr4_5jkg.pdbqt`, `FGFR4_clean_receptor.pdb` — FGFR4 kinase domain in DFG-in conformation bound to `6LF` (centroid `[-40.88, -16.01, 378.17]`).
  - `vegfr2_4asd.pdb`, `vegfr2_4asd.pdbqt`, `VEGFR2_clean_receptor.pdb` — VEGFR2 kinase domain in inactive Type-II DFG-out conformation bound to Sorafenib (`BAX`, centroid `[-24.62, -0.39, -10.93]`).
- `ligands_chembl/` (tracked in Git):
  - Curated human (`Homo sapiens`) binding (`assay_type = 'B'`) $\text{IC}_{50}$ datasets from ChEMBL (deduplicated by canonical SMILES, conflicting replicates with $\text{SD} > 1.0\text{ pIC}_{50}$ removed):
    - `EGFR_IC50_training_data.csv` (`9,844` compounds, `CHEMBL203`)
    - `FGFR4_IC50_training_data.csv` (`3,682` compounds, `CHEMBL1974`)
    - `VEGFR2_IC50_training_data.csv` (`9,247` compounds, `CHEMBL279`)
- `ligands_phytochemical/` (ignored in Git due to 550 MB size):
  - `phytochemical_screening_set.csv` — Full COCONUT natural products library (`738,827` compounds; `738,823` valid structures). Download from [https://coconut.naturalproducts.net/download](https://coconut.naturalproducts.net/download) (CSV Lite) and place at `data/ligands_phytochemical/phytochemical_screening_set.csv`.
- `features/` (ignored in Git; deterministically regenerated by `scripts/02_feature_engineering.py`):
  - `{EGFR,FGFR4,VEGFR2}_training_features.csv` — 21 RDKit physicochemical descriptors + 2,048-bit Morgan (ECFP4, radius 2) fingerprints.
