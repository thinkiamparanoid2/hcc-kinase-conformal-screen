# Data directory

Curated kinase bioactivity datasets, receptor structures, the natural-product
screening library, and engineered features.

## `targets/` (tracked)

| Files | Structure |
|---|---|
| `egfr_1m17.{pdb,pdbqt}`, `EGFR_clean_receptor.pdb` | EGFR kinase domain, active DFG-in, Erlotinib (`AQ4`) |
| `fgfr4_5jkg.{pdb,pdbqt}`, `FGFR4_clean_receptor.pdb` | FGFR4 kinase domain, DFG-in, ligand `6LF` |
| `vegfr2_4asd.{pdb,pdbqt}`, `VEGFR2_clean_receptor.pdb` | VEGFR2 kinase domain, inactive Type-II DFG-out, Sorafenib (`BAX`) |

Binding-site centroids and box sizes are computed at run time from the
co-crystallised ligand in chain A (step 06), not hard-coded, and the box is sized
to the ligand rather than fixed.

## `ligands_chembl/` (tracked)

`<TARGET>_IC50_training_data.csv` — one row per unique **standardised parent**
(salt-stripped, neutralised, tautomer-canonicalised, deduplicated on InChIKey),
from human (`Homo sapiens`) binding assays (`assay_type = 'B'`).

| Column | Meaning |
|---|---|
| `inchikey` | Parent InChIKey; the deduplication key |
| `canonical_smiles` | Standardised parent SMILES (what the models see) |
| `original_smiles` | As retrieved from ChEMBL, before standardisation |
| `pIC50` | 9 − log10(IC50 in nM); a point value only when `censored` is false |
| `relation` | ChEMBL `standard_relation` |
| `censored` | True when `pIC50` is a bound rather than a measurement |
| `label_kind` | `exact`, `lower_bound_potency` (`<`, `<=`), `upper_bound_potency` (`>`, `>=`) |
| `n_replicates`, `replicate_sd` | Replicate count and spread; compounds with SD > 1.0 log unit are dropped |
| `first_year` | Earliest publication year, used for the temporal holdout (when available) |

**Only uncensored rows are admissible as regression targets.**
`common.load_training(target)` enforces this; pass `exact_only=False` to include
bounds for classification or docking-enrichment work, where a `>` record is
exactly what an inactive is.

> The committed CSVs were fetched before censored relations were requested, so
> they contain **no `>` records and therefore no inactive class**.
> `results/metrics/curation_<TARGET>.json` records this as
> `censored_records_available: false`, and the report carries it as a limitation.
> Re-run `python scripts/01_fetch_chembl_data.py` with network access to populate
> the inactive class.

Current contents (ChEMBL target IDs: EGFR `CHEMBL203`, FGFR4 `CHEMBL1974`,
VEGFR2 `CHEMBL279`): see `results/metrics/curation_<TARGET>.json` for exact counts
per target, rather than numbers transcribed here that can drift.

## `ligands_phytochemical/` (not tracked, ~550 MB)

`phytochemical_screening_set.csv` — the COCONUT natural-products library.
Download "CSV Lite" from <https://coconut.naturalproducts.net/download> and place
it here. Step 05 standardises and deduplicates it to unique 2D parents before
screening, because the features (physicochemical descriptors + ECFP4) are achiral
and stereoisomer records would otherwise be counted as distinct compounds.

## `features/` (not tracked, regenerated by step 02)

`<TARGET>_training_features.csv` — 21 physicochemical descriptors +
2048-bit ECFP4 (Morgan radius 2), plus the curation metadata above. Column order
is pinned by `common.FEATURE_COLS` and asserted in step 05, so a silent reorder
fails loudly instead of corrupting predictions.
